# daydream-metricool

Media dei post social di Daydream Marketing Agency (Instagram, Facebook, LinkedIn), serviti a Metricool tramite link pubblici:

`https://raw.githubusercontent.com/Claudiodb95/daydream-metricool/main/<nome-file>`

Solo file finali (jpg, png, mp4, pdf). Nomi minuscoli con trattini; un file che cambia prende un suffisso nuovo (`-v2`, `-v3`) e non viene sovrascritto. Il calendario e gli strumenti sono nel repo `sito-daydream`, cartella `social/`; questa cartella si rigenera da `social/strumenti/prepara_pubblicazione.py`.

I contenuti realistici creati con l'IA sono dichiarati nei post, come chiede l'AI Act.
